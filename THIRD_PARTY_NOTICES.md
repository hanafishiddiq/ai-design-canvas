# Third-party notices and provenance

AI Design Canvas is an original implementation. The initial architecture is conceptually inspired by two MIT-licensed open-source projects:

- **OpenStitch** — inspiration for prompt/screenshot/sketch-oriented design workflows, reusable visual foundations, multi-screen product thinking, and portable `DESIGN.md` context.
- **OpenPencil** — inspiration for a structured editable design document, design variables, richer canvas/editor semantics, agent integration, and an external engine boundary.

No source code from either project was copied into the initial MVP represented by this repository. Their names are used only to describe architectural provenance and interoperability goals. If future commits vendor or adapt third-party source code, the applicable copyright notices and license text must be added here before release.

Other runtime dependencies retain their own licenses as declared in their respective packages.
